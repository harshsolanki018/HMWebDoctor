# HMWebDoctor Logo Asset Instructions

## Brand concept
Create an original, minimal signature-style HMWebDoctor mark.

The logo should visually belong to the same HM family as HMDevTools while remaining original.

## Required concept
- Clear HM monogram/prefix
- Readable WebDoctor wordmark
- Subtle doctor reference integrated into the geometry
- Suggested reference: minimal medical plus/cross or stethoscope curve
- No cartoon doctor
- No generic medical clip-art
- No copied/traced existing logo

## Required assets
- hmwebdoctor-logo.svg
- hmwebdoctor-mark.svg
- favicon.svg
- optional hmwebdoctor-logo-dark.svg
- optional hmwebdoctor-logo-light.svg
- social preview asset

## Technical requirements
- SVG primary
- monochrome fallback
- works on light and dark backgrounds
- readable at navbar size
- mark recognizable at 16–32px
- use currentColor or theme-aware variants when possible

## Implementation instruction
If the supplied starter SVGs are not visually strong, refine them or generate an original vector design. Do not replace them with a copied third-party asset.
