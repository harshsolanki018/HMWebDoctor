# SEO Scanner

## Checks
- Title exists and has reasonable length
- Meta description exists and has reasonable length
- H1 presence/count
- Heading hierarchy
- Canonical
- Robots meta
- robots.txt
- sitemap.xml/reference
- indexability signals
- html lang attribute
- Open Graph basics
- Twitter/X card basics
- JSON-LD/structured data presence
- Image alt coverage
- Internal/external link counts
- URL normalization/basic quality

## Principles
Do not claim a page is "SEO optimized" based on a small number of checks. Call the result a technical SEO health assessment.

Every finding should include evidence where possible.
