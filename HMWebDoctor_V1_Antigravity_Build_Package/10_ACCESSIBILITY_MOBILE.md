# Accessibility and Mobile Scanner

## Accessibility
Prefer axe-core for browser-level standards checks.

Cover where supported:
- alt text
- form labels
- headings
- landmarks
- ARIA issues
- duplicate IDs
- semantic structure
- contrast
- keyboard-related signals
- accessible names

## Mobile
Use a controlled mobile viewport/browser profile.

Check:
- viewport configuration
- responsive rendering
- horizontal overflow signals
- text/tap-target issues where reliably measurable
- mobile performance
- mobile screenshot/render

Never claim complete accessibility or mobile compliance from automated checks alone.
